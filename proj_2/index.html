Part 1.1: Convolutions from Scratch

I implemented image convolution from scratch using only numpy, in two ways: a four for loop version, which looped over every output pixel and every kernel entry, and a faster two for loop version, which looped only over the kernel and using numpy slicing to update the whole image at once. Both implementations flip the kernel and zero-pad the input so the output matches the input size. All three gave the same/similar outputs.

Four-loop convolution

This version loops over every output pixel, and for each one, loops over every entry in the kernel to compute the weighted sum directly: 

def four_for_loop(image, kernel):
    kernel_h, kernel_w = kernel.shape
    image_h, image_w = image.shape

    padded_img = np.pad(image, ((kernel_h//2, kernel_h//2), (kernel_w//2, kernel_w//2)))
    kernel_filter_flipped = kernel[::-1, ::-1]

    output = np.zeros((image_h, image_w))

    for ih in range(len(output)):
        for iw in range(len(output[0])):
            new_value = 0
            for kh in range(kernel_h):
                for kw in range(kernel_w):
                    new_value += padded_img[ih + kh][iw + kw] * kernel_filter_flipped[kh][kw]
            output[ih][iw] = new_value

    return output

Two-loop convolution

This version only loops over the kernel entries, and uses numpy slicing to update the entire output image at once for each kernel entry, avoiding the two innermost pixel loops entirely: 

def two_for_loop(image, kernel):
    kernel_h, kernel_w = kernel.shape
    image_h, image_w = image.shape

    padded_img = np.pad(image, ((kernel_h//2, kernel_h//2), (kernel_w//2, kernel_w//2)))
    kernel_filter_flipped = kernel[::-1, ::-1]

    output = np.zeros((image_h, image_w))

    for kh in range(kernel_h):
        for kw in range(kernel_w):
            output += kernel_filter_flipped[kh, kw] * padded_img[kh:kh + image_h, kw:kw + image_w]

    return output

Runtime comparison

The runtime for the four for loop one is significantly lower running for 295.94s, while the two for loop and scipy runtime were 1.30s and 1.16s, respectively.

Boundary handling

Boundaries are handled via zero-padding. The image is padded with zeros on all sides before convolving, so every output pixel has a full neighborhood to work with. This can slightly darken or distort values very close to the image edges, since the filter is averaging against fabricated zero values rather than real image content there.

Part 1.3: Derivative of Gaussian (DoG) Filter

Blurring the cameraman image with a Gaussian filter before differentiating suppresses the noise seen in Part 1.2. I compare this two-step process (blur, then differentiate) against a single-step process using a combined DoG filter (Gaussian convolved directly with D_x / D_y).

How I built it

To build the 2D Gaussian filter, I used cv2.getGaussianKernel(size, sigma) to get a 1D Gaussian, then took its outer product with its own transpose to spread it across both dimensions: 

def gaussian_2d(size, sd):
    g1d = cv2.getGaussianKernel(size, sd)
    g2d = g1d @ g1d.T
    return g2d

This works because a 2D Gaussian is separable — it can be exactly decomposed into the product of two 1D Gaussians, one per axis — so the outer product gives an exact 2D Gaussian, not an approximation. I chose the kernel size as 2 * ceil(3 * sigma) + 1, which keeps roughly 3 standard deviations of the curve on each side of the center and guarantees an odd size (so there's always a well-defined center pixel).

For the two-step approach, I blurred the image with this Gaussian, then convolved the blurred result with D_x and D_y separately. For the single-step DoG approach, I instead convolved the Gaussian filter itself with D_x and D_y first, producing two small combined filters, then convolved the original (unblurred) image with those directly: 

def DoG_filter(gaussian, Dx, Dy):
    DoG_x = two_for_loop(gaussian, Dx)
    DoG_y = two_for_loop(gaussian, Dy)
    return DoG_x, DoG_y

Both approaches use the same two_for_loop convolution function from Part 1.1 — the only difference is whether the blurring and differentiating happen as two separate convolutions against the image, or as one convolution against a pre-combined filter.

Part 2.1: Image Sharpening (Unsharp Masking)

A Gaussian filter is a low-pass filter: convolving with it keeps only an image's low frequencies (smooth, slowly varying content) and removes fine detail. Subtracting that blurred version from the original image isolates the high frequencies (edges, texture) that the blur removed. Adding some extra amount of that high-frequency content back onto the original makes the image appear sharper. Algebraically, this collapses into a single combined filter: (1 + alpha) * impulse - alpha * gaussian, where the impulse filter (a single 1 at the center, 0 elsewhere) represents "the unmodified original image" in the language of convolution, so the whole operation can be done with one convolution instead of three separate steps.

Part 2.2: Hybrid Images

A hybrid image combines the high frequencies of one image with the low frequencies of another. When clost the eye is dominated by high-frequency detail, so the sharp image is seen. However, from a far only the smooth low-frequency content can be seen, so the blurry image is seen instead. Each input image's cutoff frequency (sigma) was chosen experimentally — too low a sigma for the high-frequency image leaves residual low-frequency content that causes ghosting; too high a sigma for the low-frequency image destroys recognizable structure.

Part 2.3: Gaussian and Laplacian Stacks

A stack is like a pyramid but without downsampling, every level stays the same resolution as the original image. Each Gaussian stack level is the previous level blurred again with the same Gaussian filter. Each Laplacian stack level is the difference between consecutive Gaussian levels (capturing the band of detail removed by that blur step); the final Laplacian level is simply the last, most-blurred Gaussian level, kept as-is. Summing every Laplacian level reconstructs the original image exactly.

Part 2.4: Multiresolution Blending (the Oraple!)

To blend two images without a visible seam, I build a Gaussian stack and Laplacian stack for each input image, plus a Gaussian stack for the blending mask itself. At each level, I combine the two images' Laplacian levels using that level's blurred mask as the blend weight (mask * laplacian_A + (1 - mask) * laplacian_B), then sum every blended level to get the final result. Blurring the mask at each level — rather than using one hard cutoff for every frequency band — is what makes the seam disappear.
